# Fork notes — what changed, and where it lives

Miaurmario forked from [Anyesh/wardrowbe](https://github.com/Anyesh/wardrowbe)
on 2026-07-21, at upstream `1.5.1`. This file is the engineer's map: which
directories hold the fork's work, and which parts of the original are still
underneath. For *when* things happened, see [CHANGELOG.md](CHANGELOG.md); for
what the product is, see [README.md](README.md).

The fork no longer tracks upstream. Nothing has been merged from it since the
fork point, and the two have diverged far enough that merging is not planned.

## What is still upstream's

Mostly untouched, and worth knowing about before you go looking for a bug:

- **The learning engine** — `backend/app/services/learning_service.py`,
  `backend/app/api/learning.py`, `frontend/app/dashboard/learning/`. Colour
  preferences and item-pair scores learned from accept/reject feedback.
- **Pairings** — `backend/app/api/pairings.py` and the matching frontend route.
- **Analytics** — `backend/app/api/analytics.py`.
- **Wash tracking** — wear counters and wash intervals on the item model
  (`backend/app/models/item.py`), and the laundry reminder in
  `backend/app/workers/notifications.py`.
- **Families** — `backend/app/api/families.py` and `frontend/app/dashboard/family/`.
  Still wired up, but hidden from the navigation since `Amigos` replaced it as
  the social layer.
- **OIDC sign-in**, ntfy and Mattermost notification providers, and the
  Kubernetes manifests in `k8s/`. All inherited; none of them are exercised by
  this deployment, so treat them as unverified.
- **Nginx** config in `nginx/`, and the general FastAPI / SQLAlchemy / arq
  skeleton.

## What the fork added

### Brand and design system — "Stinky pop"

Whering-inspired, mobile-first: white canvas, `#F4F4F2` panels behind garments,
ink text, pill buttons and inputs, and saturated blocks taken from the mascot —
bubblegum pink `#FF7EB6` (Stinky's nose), amber `#FFB81C` (his eyes), sky
`#56C2FF`, mint `#3FD99A`. Figtree for UI text, Bagel Fat One only for the
wordmark. Dark theme included.

- `frontend/app/globals.css` + `frontend/tailwind.config.js` — every colour is a
  CSS variable, so a palette swap is one file.
- `frontend/components/ui/*` — pill buttons (`default` ink, `secondary` gray,
  `signature` pink), pill inputs, rounded cards and dialogs.
- `frontend/components/{header,sidebar,mobile-nav}.tsx` and `nav-items.ts` — the floating
  glass dock with a pink active pill, and the profile menu behind the avatar.
- `frontend/components/stinky/` + `frontend/public/brand/stinky/head/` — the
  mascot (`<Stinky state="idle|thinking|happy|wave|sleepy|sad">`), animated WebP
  built from photographs of the real cat, with reduced-motion posters and a dark
  variant.
- `frontend/components/{page-header,chip,empty-state,stinky-tip}.tsx` — shared
  building blocks.

Reference: [`frontend/DESIGN-SYSTEM.md`](frontend/DESIGN-SYSTEM.md).

(An earlier rebrand pass — cream, burgundy, Playfair — was replaced wholesale by
this one. `docs/outfit-builder.md` still describes the canvas in those terms in
places; the mechanism it documents is current, the colours are not.)

### i18n — next-intl v3, no URL routing

- `frontend/messages/{es,en}.json` — the full catalogue. Spanish is not a
  translation layer here; it is the source language, and English follows it.
- `frontend/i18n/request.ts` — locale from the `wardrowbe_locale` cookie,
  defaulting to `es`. No `Accept-Language` sniffing: the default is deliberate.
- `frontend/components/language-switcher.tsx` — mounted in
  Ajustes → Apariencia, on `/login` and on `/onboarding`.

Remaining English surfaces: [`frontend/I18N-TODO.md`](frontend/I18N-TODO.md).

### PWA

- `frontend/public/manifest.webmanifest`, `frontend/public/sw.js` (cache-first
  for static assets, network-first for HTML, never `/api/*` or `/_next/data/*`),
  `frontend/components/sw-register.tsx`.
- Icons generated by `frontend/scripts/generate-icons.mjs`. Bump `CACHE` in
  `sw.js` whenever a shell asset changes.
- iOS splash screens, `viewport-fit=cover`, a per-build cache name and an
  in-app update prompt.

### Auth

- Magic link and an optional argon2 password, both in `backend/app/api/auth.py`,
  with sliding token refresh.
- `frontend/lib/auth.ts` — the NextAuth v4 configuration, including the
  per-request origin derivation that lets the LAN hostname and the public
  hostname coexist.
- Invite-only sign-up enforced on every account-creation path, plus a public
  waitlist (`backend/app/api/waitlist.py`) that emails and pushes the admins.
  The mode itself is an app setting (`signup_mode`), not an env var.

### Stinky, the stylist

- `backend/app/prompts/` — the Spanish stylist prompts.
- `backend/app/services/stinky_chat/` — the streaming chat, its wardrobe tools
  and the loop cap. Needs an unbuffered nginx location; see `nginx/`.
- `backend/app/api/stinky_memory.py` — the per-user memory Stinky writes for
  himself and reads back into his prompt.
- `backend/app/services/ai_access.py` and `backend/app/api/ai_settings.py` —
  three access modes (none / granted by the admin / bring-your-own-key) and
  per-user token accounting.

### Social — Amigos

Friendships by handle (`/dashboard/friends`), per-outfit visibility (private · friends ·
public), a feed grouped per friend and day, reactions and comments
(`OutfitRating` with `scope=friend`), an in-app badge and the `/u/{username}`
invite page. Migration `social2609`.

Only the handle is ever exposed — never an email-derived name. Item images of a
shared look are reachable only through signed URLs from endpoints that passed
`can_view_outfit_socially`.

### Everything else

- **Day moments** — several looks per day with suggested transitions
  (`backend/app/api/days.py`).
- **Music** — Spotify and Last.fm listening history folded into a daily mood
  (`backend/app/api/music.py`, `backend/app/workers/music.py`).
- **Pinterest** — OAuth, import and refresh (`backend/app/api/integrations/`,
  `backend/app/workers/pinterest.py`). The app is still awaiting API approval,
  so the page is status-driven and says so out loud.
- **Selfie** — «qué llevo puesto» (`backend/app/api/selfie.py`).
- **Cut-out eraser** — brush strokes that edit the stored alpha, with
  `backend/scripts/backfill_cutouts.py` for existing wardrobes.
- **Admin panel** — `backend/app/api/admin_panel.py`, `backend/app/workers/admin.py`.
- **Location** — city and IANA timezone only, rounded to two decimals in the
  browser and again in `backend/app/api/location.py`.
- **Outfit Studio canvas** — the free-form drag-and-drop lookbook page. Contract,
  migration and the DnD-library trade-offs: [`docs/outfit-builder.md`](docs/outfit-builder.md).

## Deployment

Both images are built from this repository. Nothing is published to a registry,
so `docker compose` builds them locally; `BACKEND_IMAGE` and `FRONTEND_IMAGE`
override the tags if you push them somewhere yourself.

```bash
docker compose -f docker-compose.prod.yml build backend frontend
docker compose -f docker-compose.prod.yml run --rm backend alembic upgrade head
docker compose -f docker-compose.prod.yml up -d --force-recreate backend worker frontend
```

The backend image carries the rembg weights (`u2net`, `isnet-general-use` and
`birefnet-general-lite`), which is most of its size. In front of the stack sit
nginx (in the compose file) and then Caddy and a Cloudflare Tunnel on the host,
which are configured outside this repository.
